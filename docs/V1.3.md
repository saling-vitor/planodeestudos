## Regras herdadas

1. `main` representa produção estável.
2. Alterações começam em `develop/v1.3`.
3. Preservar dados, URLs, localStorage, backups, contestId e IDs/namespaces dos mapas.
4. Manter modelo local-first.
5. Mudança visual exige auditoria desktop + tablet/iPad + celular.
6. Mudança de dados exige Data Safety.
7. Mudança de PWA/cache exige cold-offline e teste no deploy real.
8. Mudança de mapas exige a matriz real dos materiais.
9. O gate `Validar desenvolvimento` continua atendendo `develop/**`.
10. ALTERAR → SALVAR → VALIDAR → REGRESSÃO → CONTINUAR.
