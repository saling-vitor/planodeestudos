# Plano ARQ · V1.2.0 Release Notes

Estado atual: **Release Candidate 1 aprovado no Gate V1.2 RC #1; QA manual ainda pendente.**

A V1.2 é um ciclo de **segurança, manutenção e sustentabilidade técnica**. Não introduz redesign nem reconstrução de fluxos já existentes.

## Safety Rails

- workflow genérico **Validar desenvolvimento** para `develop/**`;
- CI contínuo separado dos gates de RC/release;
- feature freeze formal com validação do diff real pós-freeze;
- histórico Git completo no gate;
- alterações funcionais fora da allowlist são bloqueadas após o freeze.

Functional freeze:

`84afc81faf45af6d67ee9e3441d5f1204734bccd`

## PWA e versionamento

- `assets/js/pa-pwa-v01.js` é a fonte única da versão-base PWA;
- Service Worker, Offline Pack e versão de deploy são derivados automaticamente;
- `pages.yml` não contém mais o número-base PWA hardcoded;
- validadores impedem divergência entre runtime, worker, pacote offline e deploy;
- a versão pública permanece **1.1.0** durante o RC.

## Mapas

Manutenção conservadora do CSS compartilhado:

- 581.558 → 580.305 caracteres;
- 240 → 227 blocos `@media`;
- 37 regras/grupos vazios removidos;
- 6 `@media` idênticos adjacentes fundidos;
- 2 pares de regras adjacentes equivalentes fundidos;
- 9.341 `!important` preservados conscientemente;
- auditor permanente impede retorno dos resíduos removidos.

Não houve alteração intencional de design, breakpoint, ID, namespace ou progresso dos Mapas.

## Portal

- Configurações e Biblioteca reutilizam `pa-contest-context-v01.js`;
- o shell delega ao contexto compartilhado quando disponível e mantém fallback;
- nenhuma função genérica foi criada artificialmente;
- `index.html` preserva sua rotina própria de migração/persistência;
- auditor permanente bloqueia reintrodução da mesclagem duplicada de concursos.
