Proteção das configurações

PIN local deste dispositivo
Privacidade localBloqueie toda a área Configurações com um PIN

O PIN é global para esta área neste dispositivo, fica somente local, não vai para o Supabase e não entra nos backups.

Sem PIN
Novo PIN: exatamente 6 números. A aba volta a bloquear no reload, hard reload, URL direta, nova aba, logout e após o tempo de inatividade escolhido. Depois de 5 erros, há atraso progressivo entre tentativas.
Modo manutenção

Pausa temporariamente nuvem, sincronização, Service Worker, cache offline e automações. Quando o build bloqueia este modo, somente uma nova publicação de produção pode encerrá-lo com segurança.
